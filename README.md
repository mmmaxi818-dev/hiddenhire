# HiddenHire — Maximilian mobility pilot

Job-search assistant seeded for **Maximilian Mugrauer** (mobility / GIS / transport planning) with **live verified openings** in Germany, Switzerland, Singapore and Hong Kong, match scores, and a CV Builder.

## Run

```bash
npm install
npm run dev
```

Optional:

```bash
export ANTHROPIC_API_KEY=…   # /api/generate (else mock templates)
export RAPIDAPI_KEY=…        # /api/reviews (else curated snapshots)
```

## Stack

Vite · React · TypeScript · Tailwind · react-router-dom · mammoth · jspdf · html2canvas · pdfjs-dist
